# Аналіз залишкового ризику — Golden dataset L03

Набір: `golden.jsonl`, `set_hash` `b4c3b413b6e9`. Мандат: **Ship it**. Рішення: **відправляти automated daily gate, але не оголошувати безумовний product release**. Baseline — 30/30, `lesson-03` — 14/30; D19, D20, D21, D22 і D26 виявляються.

| Що не покрито | Що станеться, якщо зламається | Відкласти чи прийняти | Чому живемо з цим зараз |
|---|---|---|---|

| Довга пам'ять поза одним сценарієм `MEMORY-018` | сума або контекст губляться в інших діалогах | відкласти до L05 | один release-кейс не вимірює розподіл довжин розмов |
| Точність аргументів усіх tool calls | правильний текст може приховати неправильні аргументи дії | відкласти до L07 | зараз payload assertions покривають лише п'ять найкритичніших відповідей |

| Українська/польська та ширший набір валют | локалізація або currency formatting можуть зламатися | прийняти тимчасово | Seed-етап і низький поточний обсяг; розширювати за complaint volume |

Скарги поза набором: **C-07** — немає customer/account/transaction, тому оракул неможливо прив'язати; **C-15** — зависає мобільний застосунок, це не збій агента; **C-16** — бот правильно повідомив про відсутність cashback, скарга не задає помилкової поведінки; **C-20** — немає імені, дати, питання чи відповіді.

## 3. Розмір набору

Daily-гейт: `30 × 1 = 30` мінімальних case invocations. У clean baseline через tool loops фактично було **64 model calls**, 88,659 input + 30,767 output = **119,426 tokens**. Модель: `gpt-5-mini-2025-08-07`.

Вартість одного clean-прогону без кешування:

`88,659 × $0.25/M + 30,767 × $2.00/M = $0.0837`.

Це точніше за формулу з однією середньою ціною, бо input і output мають різні тарифи. Provider console для доступного Personal/Default project 8 жовтня показала `$0.00`, 0 tokens, 0 requests; вона не містить usage ключа стенду, тому фактичне списання не підтверджене. Оцінка спирається на usage raw report і не видається за invoice.

Повторний третій прогін: **61 model call**, 86,963 input + 85,508 output = **172,471 tokens**; uncached estimate: `86,963 × $0.25/M + 85,508 × $2.00/M = $0.1928`.

Чутливість: numeric override змінив результат на **19 кейсах із 30** (30/30 → 11/30). Ресурсний профіль проти baseline: input -1.9%, output +177.9%, total tokens +44.4%, latency +120.3%; один прогін не дозволяє приписати ресурсні зміни промпту причинно. Два додаткові числові кейси фактично змінили відповіді, але не verdict через `tolerance=1`; це окремо зафіксований ризик метрики.

За протилежного мандату **Zero regulatory risk** daily-гейт сам по собі був би недостатнім: `SAFE-010`, `COMPLETE-014`, `TON-002`, `TON-017` і `MEMORY-018` стали б blocking release-checks із каліброваним judge/людиною; D19/D22/D26 та всі critical cases вимагали б 100%, а retrieval provenance і provider resilience треба було б закрити до релізу, а не відкладати.
